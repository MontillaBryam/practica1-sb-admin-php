# Práctica 1: SB Admin 2 en PHP

Este proyecto convierte la plantilla SB Admin 2 de HTML a PHP. Se cambiaron las extensiones de sus páginas y se actualizaron los enlaces internos para que la navegación funcione correctamente.

## Abrir el proyecto

Con Laragon iniciado, abre:

http://localhost/practica1/

## Contenido

El proyecto incluye el panel principal, páginas de demostración de componentes y utilidades, y pantallas de inicio de sesión, registro y recuperación de contraseña. También conserva los estilos, scripts, imágenes y recursos Bootstrap de la plantilla.
